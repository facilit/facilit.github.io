Quando uma instituição cadastra dezenas de tags para organizar Entidades e Indicadores, encontrar a tag certa na hora de selecionar vira um desafio: a lista cresce, os nomes se parecem e a equipe perde tempo rolando um menu extenso até achar o item desejado.

Para resolver isso, a lista de seleção de tags agora organiza automaticamente os itens em **agrupadores**, com base em um prefixo padronizado (por exemplo, `Secretaria:`, `Programa:` ou `Status:`). Em vez de uma lista longa e desordenada, o servidor passa a enxergar as tags já separadas por tema, podendo expandir apenas o grupo que interessa no momento.

O resultado é uma seleção mais rápida e intuitiva, tanto na tela de uma Entidade quanto na tela de um Indicador — reduzindo o tempo gasto procurando a tag certa e diminuindo o risco de selecionar a tag errada por engano.

💡 **Disponibilidade:** o agrupamento é aplicado automaticamente sempre que as tags cadastradas seguirem um padrão de prefixo e separador (`:`). Tags sem esse padrão continuam sendo exibidas normalmente, fora de agrupadores.

## Agrupamento de Tags na Seleção de Entidades e Indicadores

## Como acessar

1. Acesse a página de uma **Entidade** ou de um **Indicador**.
2. Localize o campo de seleção de **Tags**.
3. Clique no campo para abrir a lista de opções.

## Passo 1 — Cadastrando tags com prefixo de agrupamento

Para que o agrupamento funcione, as tags devem ser cadastradas usando um prefixo seguido de dois-pontos (`:`) antes do nome específico. Por exemplo, uma Secretaria de Planejamento que organiza suas tags por tema pode cadastrar:

| Tag cadastrada | Agrupador exibido | Item exibido dentro do grupo |
|---|---|---|
| `Programa: Educação` | Programa | Educação |
| `Programa: Saúde` | Programa | Saúde |
| `Status: Em execução` | Status | Em execução |
| `Status: Concluído` | Status | Concluído |

Tudo o que vier antes do `:` forma o nome do agrudador; o que vier depois é exibido como item dentro dele.

## Passo 2 — Selecionando tags agrupadas

Ao abrir o campo de seleção de tags em uma Entidade ou em um Indicador, a equipe verá os agrupadores listados em vez de uma lista única. Para usar um grupo:

1. Clique sobre o nome do agrupador (por exemplo, **Programa**) para expandi-lo.
2. As tags associadas àquele grupo aparecem logo abaixo.
3. Selecione uma ou mais tags dentro do grupo normalmente.

Em um órgão que acompanha vários programas simultaneamente, isso evita que o gestor precise rolar uma lista longa: ele abre diretamente o agrupador **Programa** e enxerga só as opções daquele tema.


## Passo 3 — Tags sem prefixo

Tags cadastradas sem o padrão de prefixo continuam aparecendo normalmente na lista, fora de qualquer agrupador — nenhuma tag existente é perdida ou precisa ser recadastrada.

## Dicas para melhores resultados

✅ **Padronize os prefixos da equipe:** combine com os times quais prefixos serão usados (ex: `Secretaria:`, `Programa:`, `Status:`) antes de cadastrar tags em massa, evitando agrupadores duplicados por variação de escrita.

✅ **Revise tags antigas:** se sua instituição já tem muitas tags cadastradas sem prefixo, avalie renomeá-las para aproveitar o agrupamento e organizar a lista existente.

✅ **Use nomes curtos para os agrupadores:** prefixos objetivos (uma ou duas palavras) deixam a lista mais limpa e fácil de escanear visualmente.

## Conclusão

O agrupamento de tags transforma uma lista longa e confusa em um menu organizado por tema, tornando a seleção de Entidades e Indicadores mais rápida e assertiva. Pequenas mudanças no cadastro das tags — como adotar um prefixo padrão — já trazem ganho imediato de organização para toda a equipe.
